One short joke about office life (at most 200 characters), entered in the
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
bounty on [make.fun](https://make.fun).

## The joke

> I filed my leave request three months early. It is still pending, and so, apparently, am I.

## How it works

`main.ts` reads the single-line joke from `entry.txt` and writes it to
`/output/entry.txt`, where the judge reads it. Run it with Node 22+:

```sh
node main.ts
```
